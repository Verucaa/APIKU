CARA PAKAI

Enam langkah — dari kosong sampai endpoint yang di-deploy. Library fetch bawaan Node 18+, tanpa dependency scraping.

1

INSTALL & JALANKAN

npm install && npm start — server naik di localhost:3000, UI otomatis terbuka.

2

BUAT FILE PLUGIN

Taruh file .js di src/plugins/<kategori>/ — router otomatis jadi /<kategori>/<nama-file>.

3

DEFINISIKAN PARAMS

Schema params menjadi kolom input di UI sekaligus validasi (string / number / boolean).

4

ATUR CACHE & TIMEOUT

Tambahkan cache: 60 (detik) dan timeout: 15000 (ms) langsung di file plugin.

5

UJI DI BROWSER

Buka halaman Endpoint, klik kartu, isi form otomatis, lihat response sukses/gagal.

6

DEPLOY KE VERCEL

vercel atau push ke GitHub — langsung live secara serverless tanpa konfigurasi.

// TEMPLATE PLUGIN — salin kode ini 
// src/plugins/info/jam.js  ->  GET/POST /info/jam
export default {
  name: "Jam Sekarang",
  category: "info",
  description: "Menampilkan waktu server (contoh plugin terbaru)",
  method: ["GET", "POST"],
  cache: 30,
  params: {
    zona: {
      type: "string",
      required: false,
      description: "Zona waktu, contoh Asia/Jakarta"
    }
  },
  execute: async ({ query, body }) => {
    const zona = query.zona || body?.zona || "Asia/Jakarta";
    return { zona, waktu: new Date().toLocaleString("id-ID", { timeZone: zona }) };
  }
};
